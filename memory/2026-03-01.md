## Design Decisions
- Public Speaking pillar uses speaking sessions for progress, not concept tree
- OpenAI gpt-4o-transcribe for STT (best accuracy for technical jargon)
- Wispr Flow has no API — built our own recording pipeline with expo-av
- Speaking eval is separate from learning eval (different dimensions)
